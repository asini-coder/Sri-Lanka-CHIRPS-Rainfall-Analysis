# Folder guide

- `notebooks/final/`: the six official final notebooks, unmodified
- `notebooks/visualization/`: original supplied model visualization copy
- `notebooks/exploratory/`: selected cleaning, buffering and research plotting notebooks; optional
- `gee/core/`: high-priority extraction scripts for CHIRPS, ERA5, Copernicus
- `gee/supplementary/`: earlier test and consistency scripts
- `results/`: final notebook-generated aggregate tables and figures (public: no record-level predictions)
- `data/`: documentation only in GitHub version; full datasets in private submission archive
- `report/`: review copy of technical report (where available)
- `docs/`: methodology, extraction, hypothesis assessment, citations, reproduction instructions

**No original filenames, relative paths inside notebooks, URLs, or JavaScript source content were modified.** File placement is organizational; original notebook cells may still expect original project paths.
