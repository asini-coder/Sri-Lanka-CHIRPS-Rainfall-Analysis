# Data inventory and sharing controls

| Location in private submission | Contents | Public repository? |
|---|---|---|
| `data/ground/` | Six station gauge inputs, coordinates | **No**, pending permission |
| `data/processed/` | Cleaned gauge data and merged CHIRPS/ERA5/terrain tables | **No**, pending permission |
| `data/chirps/` | CHIRPS v2/v3 point and buffered CSV exports | Not mirrored; original provider provenance required |
| `data/era5/` | ERA5 annual atmospheric exports | Not mirrored; link and licensing to verify |
| `data/copernicus/` | DEM and gradient extracts | Not mirrored; source credit required |
| `data/enso/` | Niño indices/anomalies | Not mirrored; source credit required |

The README is not a claim of a complete original-gauge public release. The ZIP supplied by the user contains all listed data folders; consult that source for full provenance. Public posting of third-party station observations is subject to permission, regardless of inclusion in a coursework submission.
